VALUE LOOKUP

Find the item. Get the numbers.

Use /value and type an item name. The bot shows the listed value, range, demand, rarity and stability.

Typo matching If the name is close, the bot suggests the item you probably meant.
Unique items If MM2Values lists an owner instead of a range, the bot shows the owner.
Source shown You can see where the value came from in the result.
