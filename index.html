VALUE LOOKUP

One command. The fields that actually matter.

Type an item name and the bot returns the source value alongside range, demand, rarity and stability. Typo matching helps when the item name is close but not exact.

Exact source values No fake “example value” placeholders.
Fuzzy matching cnady can still lead you to Candy.

Useful signal, not a database census.

The command is designed to show item changes such as value increases and decreases. If the bot has no previous cache snapshot to compare against, it simply says that no changes have been detected yet.

Your channels, your layout.

Admins can configure two independent destinations: one for value changes and one for MM2 game updates. Either feed can use an existing channel, create a default channel, or be disabled.
