Privacy Policy

Last updated: 31 August 2026

What the bot uses

The bot uses the information needed to respond to slash commands and run server features, including command options and Discord server or channel IDs used by setup.

What it does not need

The current command set does not require Message Content, Presence or Server Members privileged intents. The bot is not designed to read normal private conversations or collect passwords, payment information or Roblox login details.

Server settings

In the current v1 build, setup settings are stored in memory and may reset when the bot restarts. Persistent storage is planned.

Value data

MM2 item data is pulled from MM2Values and cached so the bot can answer value commands and detect changes between refreshes.

Third-party services

Discord, GitHub Pages, the hosting provider and MM2Values may process data under their own policies when you use those services.
