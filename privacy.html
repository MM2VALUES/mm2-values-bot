Privacy Policy

Last updated: 31 August 2026

What the bot processes

MM2 Values Bot processes the information required to respond to Discord interactions, such as the command you use, the options you provide, and the server context needed for server-specific features.

Server configuration

The setup feature can store Discord server and channel identifiers so the bot knows where configured updates should go. In the current v1 build, this configuration is held in process memory and can reset when the bot restarts.

What we do not need

The bot does not require Discord Message Content, Presence, or Server Members privileged intents for its current command set. It is not designed to read ordinary private conversations or collect passwords, payment details, or Roblox account credentials.

Value data

MM2 item data is retrieved from MM2Values and cached by the bot to answer commands and detect value changes. Source attribution is shown in bot responses where relevant.

Third parties

Discord, the bot hosting provider, GitHub Pages, and MM2Values may process data under their own policies when you use their services or visit their websites.

Changes

This policy may be updated as the bot gains persistent storage or additional features. The date above will be changed when the policy is materially revised.
