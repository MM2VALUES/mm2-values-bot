## IMPORTANT - Discord invite link
Open `script.js` and replace:

`PASTE_YOUR_DISCORD_INSTALL_URL_HERE`

with the installation URL from Discord Developer Portal → Installation.

That single value powers every **Add to Discord** button on the site.
